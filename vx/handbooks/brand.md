# Brand

## Vezham And Vx

- **Vezham** is the company and product brand.
- **Vx** is the framework and toolkit identity used inside this workspace.
- **vx** is used for code, config, package prefixes, and runtime attributes, such as `@vx/*`, `vx.app.yaml`, and `data-vx-*`.
- **@vx/** packages are workspace-local and private to this monorepo.
- **@vezham/** packages are reserved for public npm packages, global tools, and external developer-facing APIs.
- Uppercase sentinel and environment-style names may stay uppercase, such as `V_APP_*` and `VX_METADATA_START`.

## Usage

```ts
// Public packages and global tools
import { something } from '@vezham/something'

// Local workspace toolkit
import { defineAppConfig } from '@vx/config/vite'
import { defineConfig } from '@vx/start/tanstack'
```

| Usage                 | Form                                     |
| --------------------- | ---------------------------------------- |
| Brand                 | Vezham                                   |
| Workspace toolkit     | Vx                                       |
| Package scope         | `@vx/*`                                  |
| Config files          | `vx.app.yaml`, `vx.deploy.yaml`          |
| Env/data attributes   | `V_*`, `data-vx-*`                       |
| CSS custom properties | `--vx-*`                                 |
| Types/classes         | `VxConfig`, `VxMetadata`, `VxApp`        |
| Variables             | `vxConfig`, `vxMetadata`                 |
| Generated text        | `Generated by Vx metadata. DO NOT EDIT.` |

Use `--vx-*` for Vx-owned CSS custom properties, such as `--vx-header-height`.
Preserve CSS custom property names provided by third-party libraries and frameworks.
